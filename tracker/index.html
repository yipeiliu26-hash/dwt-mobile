資料怎麼更新

按上方「連結資料夾」選一個本機資料夾,之後每週把 WMS 不良品倉匯出檔(.xlsx)丟進這個資料夾(或它的子資料夾),回到這個頁面就會自動讀取新檔案。看板的資料(每週快照、處理狀態/Owner/預計完成時間)會存在同一個資料夾的 tracker-data.json。

不良品倉資料/            ← 連結這個資料夾
  WMS匯出/
    record_1019.xlsx      ← 每週 WMS 匯出檔(工作表 Data)
    record_1026.xlsx
  tracker-data.json       ← 看板自動建立/更新,請勿手動修改
  tracker-data.backup.json ← 每次開啟後第一次儲存前的備份

這個瀏覽器不支援直接讀取資料夾(請用 Chrome 或 Edge)。目前改用「匯入WMS檔案」手動選檔,資料存在這個瀏覽器裡;建議定期用下方「下載資料備份」保存一份。

每份檔案的週次以檔案內「年月日」欄位判斷;同一天有兩份檔案時,以修改時間較新的為準。不是 WMS 匯出格式的 Excel(例如看板自己匯出的檔案)會自動略過。
